# 항만 컨테이너 물동량 분석 대시보드

## 프로젝트 소개

공공데이터포털의 항만 컨테이너 물동량 데이터를 활용하여 부산항의 물동량 현황과 항만별·시설별 운영 특성을 분석한 개인 프로젝트입니다.

월별 물동량 추이, 수출입·환적 구성, 적컨·공컨 비중, 컨테이너 규격별 비중 등을 대시보드로 구현하여 사용자가 조건을 변경하며 데이터를 확인할 수 있도록 제작했습니다.

## 프로젝트 개요

- 프로젝트 유형: 개인 프로젝트
- 개발 기간: 5일
- 분석 기간: 2024년 1월 ~ 2024년 12월
- 개발 환경: PyCharm
- 배포 환경: Streamlit Cloud

## 사용 기술

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## 데이터 출처

- 출처: [공공데이터포털](https://www.data.go.kr/)
- 데이터: 항만 컨테이너 물동량 데이터
- 분석 대상: 감천항, 북항, 신항 및 주요 부두
- 분석 기간: 2024년 1월 ~ 2024년 12월

## 주요 기능

### 1. 분석 조건 필터

- 월 범위
- 청코드
- 시설
- 수출입 구분
- 적컨·공컨 구분

### 2. 핵심 지표 제공

- 전체 물동량
- 전체 컨테이너 개수
- 월평균 물동량
- 최근 월 전월 대비 증감률
- 환적 물동량 비중
- 적컨 비중
- 40피트 컨테이너 비중

### 3. 시각화

- 월별 물동량 추이
- 시설별 물동량 TOP 10
- 수출입·환적 구성
- 시설별 40피트 컨테이너 비중
- 청코드별 적컨·공컨 비중
- 컨테이너 규격별 비중

### 4. 데이터 조회 및 다운로드

- 시설별 상세 실적 조회
- 분석 결과 CSV 다운로드
- 차트 이미지 다운로드

## 주요 분석 결과

기본 분석 조건 기준으로 다음과 같은 결과를 확인했습니다.

- 전체 물동량: 약 2,440만
- 환적 물동량 비중: 약 55.3%
- 적컨 비중: 약 83.4%
- 40피트 컨테이너 비중: 약 61.9%
- 시설별 물동량 1위: 신항2부두
- 신항2부두의 전체 물동량 점유율: 약 20.3%
- 시설별 물동량과 40피트 컨테이너 비중의 상관계수: 약 0.29

## 프로젝트를 통해 배운 점

- 공공데이터를 분석 목적에 맞게 전처리하는 방법
- Pandas와 NumPy를 활용한 데이터 집계 및 지표 산출
- 항만 물동량 데이터를 다양한 기준으로 분류하고 비교하는 방법

- 분석 결과를 사용자가 이해하기 쉬운 시각자료로 전달하는 방법
